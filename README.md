# Creator Titan OS

**Tagline:** Create. Automate. Dominate.

A responsive, local-first creator command center for planning videos, drafting a production pack, tracking a content pipeline, checking off daily actions, and manually recording published-video results.

## Use it
- Open `index.html` in a browser, or enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)**.
- Data is saved in that browser's local storage. Use **Export backup** to save a JSON backup.
- Draft generation uses a deterministic template. It is not connected to an AI model or web research.
- Publishing and analytics are manual. No credentials or API keys are included.

## Roadmap
1. Validate the dashboard on mobile.

4. Add cloud automation only when a real scheduler, hosting, and permitted integrations are configured.
